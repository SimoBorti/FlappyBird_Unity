# 🐤 Flappy Bird Clone (Unity & C#) - Windows only

Una ricreazione in 2D del celebre gioco **Flappy Bird**, sviluppata con il motore di gioco **Unity** e il linguaggio **C#**. 

Il progetto è stato realizzato con l'obiettivo di approfondire le dinamiche di sviluppo di videogiochi 2D, la gestione della fisica tramite rigid body e le collisioni in real-time.

---

## 🎮 Gameplay e Dinamiche
* **Meccanica principale:** Controlla il volo dell'uccellino toccando lo schermo o premendo la barra spaziatrice per evitare i tubi.
* **Sistema di Punteggio:** Incremento del punteggio ad ogni ostacolo superato con salvataggio del record (High Score).
* **Gestione Collisioni e Game Over:** Rilevamento istantaneo del contatto con il terreno o con gli ostacolo, con conseguente schermata di riavvio.

---

## 🛠️ Tecnologie Utilizzate
* **Game Engine:** Unity (2D)
* **Linguaggio di programmazione:** C#
* **Fisica & Componenti:** `Rigidbody2D`, `Collider2D`, gestione degli eventi e dello stato di gioco tramite Script Manager.
